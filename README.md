# FocusFlow – Student Productivity App

FocusFlow is a student productivity application designed to help students organize their daily activities, manage tasks, build productive habits, and improve their focus.

## ✨ Features

* 📝 Create, update, and delete tasks
* 📅 Organize daily activities
* 🎯 Set goals and track progress
* ⏱️ Use a focus timer for study sessions
* 📊 Monitor productivity
* 📱 Simple and user-friendly interface

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/Sreeja07309/FocusFlow.git
   ```

2. Open the project folder:

   ```bash
   cd FocusFlow
   ```

3. Install dependencies if the project uses Node.js:

   ```bash
   npm install
   ```

4. Start the application using the appropriate script in `package.json`.

   ```bash
   npm run dev
   ```
